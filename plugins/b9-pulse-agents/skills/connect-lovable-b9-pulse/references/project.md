# Projeto Lovable B9 Pulse

- Project ID: configure `LOVABLE_PROJECT_ID` no ambiente de operação.
- Editor: abra o projeto autenticado pelo painel do Lovable.
- Preview: configure o domínio real em `ALLOWED_ORIGINS` somente no ambiente publicado.
- Frontend: TanStack Start + TypeScript
- Chat component: `src/components/finance/PulseChat.tsx`
- Existing request path: `/api/public/pulse-chat`

The project is private and its Git history is synchronized with Lovable. Never force-push, rebase, amend, or squash commits that were already pushed.
